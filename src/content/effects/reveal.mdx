## Recipes

### Cascade across a grid

Give each image a slightly longer `delay` than the one before it. The row enters together, so the prints open one after another from left to right.

### Scrub it with the scroll

With `data-dio-trigger="scroll"` the reveal follows the scroll position both ways: the image opens as it rises to the middle of the viewport and closes again when you scroll back. Use it for a wide image that a reader passes slowly, such as a panorama between two sections.

```html
<img
  src="/media/ridges.jpg"
  data-dio="reveal"
  data-dio-trigger="scroll"
  data-dio-direction="right"
/>
```

### A quiet fade for long reads

The `fade` style drops the edge and drifts the image 40 px into place. Set `zoom` to 1 as well and an article's figures arrive without drawing attention away from the text.

```html
<img
  src="/media/prints/night.jpg"
  data-dio="reveal"
  data-dio-style="fade"
  data-dio-zoom="1"
  data-dio-duration="0.8"
/>
```

### Bands across a wide banner

The `blinds` style opens the image in bands, each half a reveal after the one before it. A low `softness` keeps the bands crisp, which suits a banner of flat shapes or type.

```html
<img
  src="/media/ridges.jpg"
  data-dio="reveal"
  data-dio-style="blinds"
  data-dio-direction="down"
  data-dio-softness="0.02"
/>
```

## Notes

An image that is already in view when the page opens stays as it is: the reveal plays only for images the reader scrolls to, so nothing on the first screen disappears to play an intro. The example on this page plays again after each change for the same reason.

The reveal starts when `threshold` of the image height is in view above the bottom tenth of the viewport. An image that only peeks in at the bottom edge has not been looked at yet, so it waits.

`style`, `trigger`, `direction` and `seed` rebuild the effect when they change. Set them in the markup rather than switching them while the image is on screen.
